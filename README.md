# My-First-SIEM-Report
This repository contains my first SIEM investigation report completed as part of a defensive security learning module. The report documents my step-by-step analysis of a security alert, including identifying the what, when, where, who, and why behind the event.

The purpose of this repo is to demonstrate my developing skills in:

Security alert analysis

SIEM navigation and investigation

Understanding source/destination activity

Interpreting internal security operations

Producing structured, clear incident documentation

This report reflects my early hands-on experience in defensive security and forms part of my ongoing journey toward becoming a SOC Analyst.
